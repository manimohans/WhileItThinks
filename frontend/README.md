# WhileItThinks Frontend

This folder contains the SvelteKit marketing landing page for WhileItThinks.

Install dependencies once:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then visit the URL printed by Vite, usually `http://localhost:5173/`.

The repository root remains the Rust/macOS backend, daemon, hook, installer, packaging, and desktop-app workspace.
